# Customer Churn Prediction – Feature Engineering & Preprocessing Pipeline

## Project Overview
This project implements a reusable Machine Learning preprocessing pipeline using Python and Scikit-Learn to predict customer churn.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Jupyter Notebook

## Implementation Steps
1. Dataset Loading
2. Exploratory Data Analysis
3. Data Cleaning and Feature Selection
4. Train-Test Splitting
5. Missing Value Imputation
6. Numerical Feature Scaling
7. Categorical Feature Encoding
8. ColumnTransformer Implementation
9. Machine Learning Pipeline
10. Model Evaluation
11. Feature Importance Analysis

## Machine Learning Algorithm
Random Forest Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

## Project Deliverables
- Jupyter Notebook
- Reusable Scikit-Learn Pipeline
- Feature Importance Visualization
- Model Evaluation Results
